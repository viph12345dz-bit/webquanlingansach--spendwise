# AI Usage Report

## Công cụ AI đã dùng
- ChatGPT – hỗ trợ phân tích yêu cầu, tổ chức mã nguồn, gợi ý và kiểm tra code.

## Các phần AI hỗ trợ
- Khung HTML/CSS/JavaScript.
- Logic LocalStorage, validation và CRUD.
- Mô phỏng Expense Categorizer, Spending Pattern Insight và Goal Coach.

## Phần sinh viên cần tự kiểm chứng/chỉnh sửa
- Kiểm tra từng luồng trên trình duyệt.
- Chỉnh giao diện bám mockup Canva/Figma.
- Hiểu và giải thích được code khi bảo vệ.
- Ghi rõ prompt, lỗi gặp phải và những chỉnh sửa thực tế của nhóm trước khi nộp.

## API thật hay mô phỏng
Hiện tại các trải nghiệm AI là mô phỏng phía Frontend; dữ liệu nghiệp vụ chủ yếu dùng LocalStorage.
