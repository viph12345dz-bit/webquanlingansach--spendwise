# AI Usage Report

## AI đã được dùng để làm gì?
- Hỗ trợ gợi ý cấu trúc giao diện.
- Hỗ trợ kiểm tra và đơn giản hóa HTML/CSS/JavaScript.

## Phần AI mô phỏng trong sản phẩm
- Expense Categorizer: phân loại bằng từ khóa JavaScript.
- Spending Pattern Insight: tính danh mục chi nhiều nhất từ dữ liệu người dùng.
- Goal Coach: chia số tiền còn thiếu thành kế hoạch 6 tháng.

Các tính năng trên không gọi AI API thật.
