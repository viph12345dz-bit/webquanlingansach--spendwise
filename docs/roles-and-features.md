# Roles and Features

## User
- Tổng quan tài chính.
- Quản lý giao dịch.
- Quản lý mục tiêu tiết kiệm.
- Thông báo, hồ sơ, cài đặt.
- AI Expense Categorizer, Spending Pattern Insight, Goal Coach.

## Coach
- Danh sách khách hàng.
- Review ngân sách.
- Quản lý tài nguyên giáo dục.

## Moderator
- Kiểm duyệt tài nguyên.
- Quản lý template AI.
- Trung tâm feedback.

## Admin
- Dashboard hệ thống.
- Quản lý danh mục chi tiêu.
- Quản lý người dùng và quyền.
