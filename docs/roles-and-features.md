# Roles and Features

## User
- Tổng quan.
- Quản lý giao dịch.
- Quản lý mục tiêu tiết kiệm.
- Thông báo, hồ sơ, cài đặt.

## Coach
- Khách hàng.
- Review ngân sách.
- Tài nguyên giáo dục.

## Moderator
- Kiểm duyệt tài nguyên.
- Template AI mô phỏng.
- Feedback.

## Admin
- Dashboard hệ thống mô phỏng.
- Danh mục chi tiêu.
- Người dùng và quyền.
