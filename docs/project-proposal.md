# Project Proposal – SpendWise

**Lĩnh vực:** Tài chính cá nhân / Financial Literacy  
**Sản phẩm:** Web Frontend nguyên mẫu nhiều vai trò, CRUD, responsive, JavaScript và trải nghiệm AI mô phỏng.

## Bài toán
Người mới quản lý tài chính thường biết mình đã tiêu bao nhiêu nhưng khó nhận ra thói quen chi tiêu, phân loại giao dịch nhất quán và chuyển insight thành hành động.

## Mục tiêu
- Quản lý giao dịch và mục tiêu tiết kiệm.
- Hiển thị dashboard và trạng thái nghiệp vụ rõ ràng.
- Có tìm kiếm, lọc, validation và CRUD.
- Mô phỏng 3 trải nghiệm AI: Expense Categorizer, Spending Pattern Insight, Goal Coach.
- Hỗ trợ các vai trò User, Coach, Moderator và Admin.
