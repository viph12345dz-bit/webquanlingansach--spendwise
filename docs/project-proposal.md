# Project Proposal

## Đề tài
SpendWise – Quản lý ngân sách và thói quen chi tiêu.

## Mục tiêu
Xây dựng website Frontend giúp người dùng quản lý giao dịch, mục tiêu tiết kiệm và các gợi ý tài chính mô phỏng.

## Phạm vi
- HTML, CSS, JavaScript cơ bản.
- Responsive.
- CRUD, search, filter, validation.
- LocalStorage để mô phỏng dữ liệu.
- Không sử dụng Backend hoặc API phức tạp.
